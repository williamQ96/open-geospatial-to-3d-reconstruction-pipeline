Beta functions

          

            Optional experiments. Off by default. Switching an experiment off
            restores the previous map activity setting.
          

          

            

          

          

            ZOMBIE SCHOOL!!! uses a shared original cartoon monster template.
            Wandering: 0.45 m/s within 12 m. Pursuit: 2.2 m/s (hero walk 1.7
            m/s; run 4.6 m/s). Spawns stay on clear terrain, never on roofs.
            Buildings and collision still apply. Contact ends the round; Restart
            restores the default map.
