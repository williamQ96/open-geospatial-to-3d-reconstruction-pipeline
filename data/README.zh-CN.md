# 数据管理

原始大数据和中间结果留在忽略的 `raw/`、`processed/` 等工作目录。来源台账记录产品 ID、URL、日期、坐标与单位、checksum、使用条件及核验结果；未知信息不伪造。

每个具体下游应另行提交 `data/reference-images/`，保存采用的图片／照片、逐图署名、许可依据、日期、用途和 hash；不要只把发布资产的来源放在忽略目录。见[图片素材规范](../docs/zh-CN/reference-media.md)。上游不重复收集各地区的照片库。

UO 实际点云、模型和名称由下游维护，上游模板仅附合成场景。原创内容 CC BY 4.0 仅覆盖项目拥有相应权利的贡献；第三方数据、字体与公有领域内容不被重新许可。代码采用 Apache-2.0，保留相应来源与署名。
