# 模拟拖拽与独立室内场景

已收录于 0.12.0／模板 0.4.0。推荐复用本设计；建筑身份、门位校正和具体室内资产仍由下游维护。

## 单一移动手势

Follow 与 First person：手指起点在下半屏则移动，上半屏则转向，角色保持到该手指抬起。6 px 死区避免误操作，48 px 摇杆半径内连续映射 0–4.6 m/s；轻拖行走（约 37% 强度为 1.7 m/s），满拖跑步。实际碰撞约束后的速度超过 2.15 m/s 才切换跑步动作；步声和模型继续共用距离相位。取消独立 Run 按钮。键盘 WASD／方向键、Shift 跑步、跳跃保留。抬手／取消／失去捕获、失焦、窗口变化、搜索、弹窗和视角切换均停止触摸移动。短促静止点击仍可操作门。

## 门位允许推断和校正

每个可用建筑轮廓生成一个实例化门框，选择面向外侧且接近点不碰撞建筑的位置，尽可能贴合美术模型立面。这不是实测入口、无障碍路线或测绘高程。下游可在 viewer-settings.json 的 entrances 按建筑 ID 覆盖 position_enu_m（东、北，米）与 outward_degrees（从北顺时针角度）；例如 {"entrances":{"building-id":{"position_enu_m":[12,34],"outward_degrees":90}}}。优先使用校正。异常重叠轮廓可能没有可用接近点，应审计覆盖率与连通性。三种视角均可鼠标点击／触摸可见门进入；第一／第三人称靠近后也可按 E 或 Enter 按钮。点击不会穿过前方建筑墙面。

## 同时只存在一个活动世界

入口模块按 URL 动态导入校园或教室。?interior=<建筑ID> 通过同源整页导航进入独立世界，而非隐藏校园后叠加室内。pagehide 时停止循环、释放几何／材质／纹理并销毁 WebGL context；返回 BFCache 缓存页面时重建已释放的资源。室内不请求校园 GLB、地面、导航与活动路径，也不生成校园 NPC。共享字体、代码、音频与角色可以利用 HTTP 缓存，这不等于校园世界继续驻留。

带版本的同标签 session 记录保留室外位置、朝向、俯仰、Follow 距离、视角、密度、晃动与显示／声音设置。门边 E 或出口按钮、顶部 Return to campus 重新加载室外后恢复。存储禁用或记录无效时回到地图默认出生点。导航、选择、NPC 轨迹、开发者模式与 beta 回合不持久化；返回后重新开始。未来更复杂资源允许有加载等待。

## 先通用模板，再逐栋深化

classroom.js 生成原创 24 × 18 m 风格化教室，含黑板、15 套桌椅、讲台、窗、天花板和出口；静态构件按材质合批，出口独立可点，墙和家具参与碰撞，Overview 隐藏天花板便于查看。室内三视角、键盘／触摸走跑、跳跃、声音与轻微视觉晃动延续熟悉操作。这是通用推断模板，不是任何建筑的真实平面图或用途断言。目前所有建筑 ID 都使用它；以后可按 ID 替换独立加载内容。

在本地 Vite 运行时，node scripts/export-classroom.mjs <输出.glb> <本地viewer网址> 可导出 Blender 等工具使用的 GLB。代码 Apache-2.0；原创模型输出默认 CC BY 4.0 并保留署名，无专有地图纹理。

## 验证

测试轮廓正反绕序、门位覆盖、拖拽速度／斜向上限、异常返回记录、鼠标／E／触摸进出、返回位置／模式／密度、桌椅碰撞、手机横竖屏。除画面外还要检查室内网络请求，避免误加载校园。上游合成例与真实下游分别验证；方法记录归上游，项目开发日志仅留在下游。


## Overview 卡片与观察式进入（收录于模板 0.4.0）

Overview 点建筑标签／模型或从搜索选择时，显示唯一的建筑锚定卡片：名称、`to be fill` 占位信息、Enter 和关闭按钮。卡片打开时只隐藏该建筑普通标签；关闭或切回人物模式后恢复。手机横竖屏均限制在可视区内，拖动地图时跟随锚点；选择不会移动 hero。

Overview 的 Enter 显式传递 interior_mode=overview，沿用独立世界资源边界。以观察者打开天花板俯览，不创建 hero、不请求其模型，室外位置仍保存在返回记录中；该观察文档不提供人物视角切换，提供 Return to campus。返回恢复室外 hero 与地图构图。普通 Follow／First-person 门口进入仍有室内 hero 和三视角。显式 URL 模式在存储禁用时仍有效，返回按既有默认出生点降级。

鼠标悬停比选中更轻微，不改变选择／不开卡片；同一建筑选中优先，移开恢复材质。独立美术模型用 emissive 轻亮；材质合批的背景用单栋轮廓边缘提示，避免整个合批一起变亮并保留批处理。按稳定轮廓 ID 解析合批命中，容忍边界浮点误差。仅鼠标移动时每 80 ms 最多执行一次待处理拾取，拖动／弹窗跳过，移出清除，触摸不制造 hover。测试状态优先级与准确 ID；不降低渲染质量或源几何。
