# 可复用浏览器模板方法

模板将重建资产、共享交互和项目内容分层。共享层包含三种视角、45° 近景、移动碰撞、跳跃、缩放、搜索、朝向镜头的标签、小地图、设置与来源展示；项目通过 profile、场景和出生偏好提供具体内容。

`init-viewer --output <新目录>` 创建含合成场景的独立项目，拒绝覆盖非空目录；`--scene-dir` 可导入已验证导出物并拒绝目录越界。`sync-viewer --output <项目>` 只升级共享代码、HTML 与 Vite 配置；文件 hash 先核查本地修改，项目数据、品牌、部署身份和凭据保持独立。首次接入使用 `--adopt`。

重建锁和模板锁分别记录实际来源；UI 升级不伪造旧几何的重建版本。模板通过真实合成 GLB、地形采样、搜索、三种模式、移动／跳跃和窄屏测试。资产署名可写入 manifest、Blender 与 GLB；代码 Apache-2.0、原创内容 CC BY 4.0，保留第三方条款。

## 美术方向

[style 库](../../style/README.zh-CN.md)默认推荐 Architectural Toon Realism，也欢迎其他画风。默认仍是合成白模，现可接入[GLB／Toon 美术层](presentation-layers.md)。风格实验不改变地理证据；通用实现评审前不修改受管运行时代码。

## 手机操作

手机使用紧凑顶栏、小地图和底部视角切换，适配安全区域。第一人称下半屏触摸产生浮动摇杆，拖拽行走、松手停止；上半屏拖拽转向，可双指独立操作。手指跨过中线不改变用途；取消、失去捕获、失焦、旋转／缩放窗口、搜索、换视角和设置均清除移动。Follow 保持拖动看向，Overview 保持环绕／捏合；桌面键鼠操作保留。
