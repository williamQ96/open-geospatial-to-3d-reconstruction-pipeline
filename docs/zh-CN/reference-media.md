# 参考图片与可导出资产

建议每个具体地图的下游仓库维护 **`data/reference-images/`**，保存实际采用的图片和照片，包括建模参考、贴图、mockup 与品牌图稿，不只保存搜索链接。第一份实例是 [Open Campus: UO 素材目录](https://github.com/williamQ96/open-campus-uo/tree/main/data/reference-images)。地区照片由对应下游维护；上游维护通用规范、校验工具和有来源记录的画风 mockup。文档默认英语，可保留中文选项。

推荐目录：

```text
data/reference-images/
  README.md / README.zh-CN.md
  manifest.json                 # 每张图片的登记
  evidence.json                 # 来源、许可声明和核验日期
  ATTRIBUTION.md                # 可阅读的署名与协议链接
  photos/<建筑或区域>/           # 获得许可的原图
  textures/                     # 若使用，记录原图及修改版本
  project/mockups/              # 标明 AI 生成情况
  project/brand/
```

保留原有设计档案和历史记录。若运行时或设计路径需要原文件，可在素材目录保存相同字节的副本并记录关系与 hash。运行截图可留在 `docs/images/` 并登记为输出，不混同照片来源。大型资料可使用 Git LFS 或持久版本化对象存储，但须核验匿名可下载、维护完整台账和可访问原件。浏览器无需下载研究素材库。

## 来源与协议

优先采用作者明确授权的自摄照片、**CC BY 4.0、CC0 或经过核验的公有领域声明**。确认允许分发原件、修改和分享／导出相关资产，包括商业复用。记录作者、来源页和具体许可；搜索结果、可下载并不等于取得授权。第三方保持原协议，项目 CC BY 仅覆盖自己拥有权利的原创贡献。

避免把授权不明、保留所有权利、NC、ND 或受平台限制的图片／模型作为开放资产流程的输入。不从受限地图、街景、瓦片或托管三维模型提取／描摹后重新声明为开放资产。无法确认许可时，不公开其图片字节；保留已有历史引用与排除原因，继续细化前换用批准的素材。不能删除过去的参考记录，也不能声称新增图库就已经重新生成旧模型。

ShareAlike 可以是开放许可，但须单独决定兼容性和分发要求，不在本项目默认 CC BY 导向的接收范围；这不等于认为所有 SA 素材都不开放。如选择采用，应明确扩展策略和校验。公有领域内容不重新加上 CC BY 限制，PD-self 不冒充 CC0。版权许可也不自动解决商标、隐私等其他权利。

## 逐图登记与建模流程

每张图记录稳定 ID、本地路径、标题、作者、来源页、下载 URL、拍摄日期（未知明确写明）、访问／核验日期、许可标识与链接、许可依据、署名、修改、SHA-256 和字节数。关联具体建筑／对象 ID 或使用它的模型、贴图、设计文件。裁剪、修图、烘焙等记录为修改，并保留原件和衍生文件的关系。AI mockup 记录生成背景，不作为地理证据。

区分背面／正面、修缮前后、历史照片和当前状况。上传日期不能代替拍摄日期；新归档待参考的图不能声称用于旧模型。来源开放不代表照片提供了精确尺寸或当前状态。

先核验来源、下载和目视检查，再在 Blender 中独立建立可编辑几何与材质，保持稳定 ID，区分美术近似和测量证据。导出标准 GLB/glTF 与通用材质；分发图片、贴图等时保留适用第三方署名和条款，项目署名不能替代作者署名。在三种视角检查，并随资产修改提交来源记录。只在应用需要时把照片加入网页运行包，保留手工细化源文件。

## 自动核查

从上游 checkout 执行：

```powershell
python scripts/check-reference-media.py --root /path/to/downstream
```

仅用 Python 标准库，检查图片登记、hash／字节数、作者／署名／许可依据／用途、来源与协议 URL、核验状态、缺失日期说明、目录逃逸和未登记图片。可选 `existing_copy` 是仓库内的相同字节副本路径，校验会发现设计／运行副本与归档不一致。默认接受 `CC-BY-4.0`、`CC0-1.0`、`LicenseRef-PD-self`。它核验记录与文件一致性，**不替代人工授权判断**，不解码图片或验证模型精度。CI 固定经过审查的 upstream commit，不直接运行不断变化的远程 main 脚本。字段示例见[英文规范](../reference-media.md)。

UO 提供实际素材台账与固定版本的 CI 实例。未确认分发权的旧引用明确排除，不偷偷改协议。媒体核查工具与重建版本、viewer 运行时版本分别记录。
