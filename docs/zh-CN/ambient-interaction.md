# 可复用密度、行走反馈与 Issue 草稿

[English](../ambient-interaction.md) | **简体中文**

模板提供与地点无关的可选交互，下载资产、配色、路线与具体反馈保留在下游。

用原生 range 控件统一 **No / Low / Mid / High**，默认 Mid，支持键盘、触屏、文字刻度及 `aria-valuetext`。改变真实活动数量，不仅调整外观。No 清空移动 NPC、固定道具、模拟与碰撞体，保留角色、地图及导航。共享目标表在 `ambience.js`；空间不足或路线无效可降低实际数量，需逐档验证。

`life.js` 按类别设置带高度区间的水平胶囊；出生时避开角色和现有对象，NPC 对角色、道具与其他 NPC 停止让行，角色每个移动子步检查动态碰撞。侧向偏移缓解迎面冲突，但拥堵仍可能停顿。这是轻量碰撞，不是刚体、完整交通 AI。关闭对象时必须移除碰撞体。

可选 `wildlife: {asset_url,yaw_correction}` 加载下游静态 GLB；`activity.squirrels.routes_enu_m` 为本地 ENU 路线，检查建筑阻挡，必要时尝试路径图。模板不自带或下载某一动物；下游归档开放许可、原模型、改编源与导出。

可选 `audio: {music_url,footstep_url}` 使用本地相对地址。声音默认开启，尝试播放，遇到浏览器自动播放限制后等待首次用户操作并重试。按钮同时控制音乐和脚步；后台暂停。未配置则隐藏按钮且不请求音频。

第一和第三视角脚步依实际地面位移触发，顶住障碍、静止、空中、总览和对话框时停止。第一视角最大约 0.018 米垂直、0.009 米侧向和 0.0025 弧度旋转的晃动只改变镜头，不改变角色或导航坐标。提供关闭选项并尊重系统减少动态效果；脚步与视觉晃动独立。第三视角镜头不晃动。

可选 `feedback: {repository:'owner/project'}` 和 `iteration` 启用下游 GitHub Issue 草稿窗口。内容必填，标题、坐标可选。坐标默认空，需明确添加。缺省标题用时间戳反馈标识及迭代号，不预判服务器 Issue 编号。打开预填 GitHub 页面，由反馈者登录并确认创建，网页保留草稿和备用链接；长内容采用复制粘贴，不截断，不内嵌写入凭据，也不在确认前宣称提交成功。内容和位置不进入统计；继续时交给 GitHub，公共仓库确认后的反馈公开。匿名直提另需防滥用后台，不属于本模板。

验证交叉胶囊、高度分离、高速移动、NPC 让行、No 档零碰撞体、数量与性能、声音开关、实际移动脚步、两种行走模式、减少动态效果、反馈必填与位置可选、UTF-8 和长草稿、窄屏布局。测试不创建真实 Issue。保留三视角、搜索、小地图及固定导航起点回归。配合[尽早可交互的社区迭代循环](iterative-community-modeling.md)，通用经验入上游方法日志，具体场景进展与反馈留在下游。
