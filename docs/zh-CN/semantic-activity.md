# 固定活动范围与按需 NPC 模板

[English](../semantic-activity.md) | **简体中文**

将“在哪里存在”与“生成什么外观”分开：人和骑行者只走标注的人行铺装，车辆只走明确选定的行车段，松鼠只在植被或已存在的树上，固定道具只用停车点位。分类属于下游场景定义，不证明实时通行或动物观测。禁止在某类路径缺失时回退到另一类路径。

`geospatial3d.activity.fixed_paths` 离线裁切中心线到所属表面，保留建筑安全间距和原始转角，预采样地形高度。路径保存稳定 ID、表面类别和 `[东,北,高度]` 点。树上路径绑定已有树，允许垂直攀爬／停栖样本。验证真实渲染的草地／铺装多边形和停车范围，而不是只检查不在建筑内部。

**活动数据升级为 version 2**：包含 `seed`、`paths` 和 `prop_slots`；移动表面为 `pedestrian / driving / vegetation / tree`。导航图仍为 version 1，两者独立。旧活动 version 1 不能静默迁移；下游先生成、审核分类路径和点位，保留历史来源，再升级共享代码。未配置普通活动的地图仍能使用探索器和 Beta。

每个 NPC 为“模板版本＋稳定 seed＋抽样属性”。固定地图 seed 与逻辑 ID 可重放外观，不依赖创建顺序。学生包含独立的 m/f 形象、1.4–2 米截断正态身高（均值 1.71、标准差 0.115）、棕黑到浅粉的连续肤色与轻微底色变化、六种原创发型、颜色、无包／手提／双肩／左或右单肩、速度及 2.15 m/s 跑步阈值。均为虚构外观，肤色不推断种族，外观不决定行为。车辆包含 car/SUV/van/pickup、颜色、大小、速度；骑行者也有独立学生属性。松鼠包含大小、毛色、速度和停顿参数，树上移动是程序化位置动画，不是骨骼攀爬。

基础素材只加载一次，共享不可变几何／纹理；密度升档只创建缺少的逻辑 ID，降档销毁多余实例并释放自有几何、材质、动画。No 应为零普通活动实例及碰撞体，而不是预建高密度后隐藏。保留仍在使用的实例；不能释放其他实例或角色共享的资源。头发／背包按骨骼附着点合批。

每帧只查缓存路径与高度，不为每个普通 NPC 重复扫描建筑和地形。保留动态碰撞与让行，狭窄道路可能排队。验证分配、销毁及分类；不要在没有实际帧时间测量时承诺 FPS 提升，模型／下载体积另算预算。

About 的 **Developer mode** 默认关闭。点击无遮挡 NPC 查看模板、seed、抽样属性、路径／点位、状态和位置，可复制复现记录。关闭入口或销毁对象时关闭面板，入口保留供未来工具扩展；这只是客户端检查，不是服务器权限。

脚步声与角色动画共用真实位移步态相位。当前探索者步行／跑步速度为 1.7／4.6 m/s，落脚间距为 0.95／1.5 米；受阻时不发脚步。第一视角默认 Low：垂直 3 毫米、侧向 1 毫米，无滚转。另设 No／Low／Mid／High 舒适度，不改变落脚相位；系统减少动态效果强制偏移置零。日志中将原步态 bugfix 与新增功能区分。

activity v2 可选 `pedestrian_regions` 支持受约束的碰撞绕行，然后回归原固定路径。范围必须是内缩的实际人行铺装，扣除孔洞、建筑和车行面；缺少或过窄时继续让行。[规划预算、碰撞余量与验证约定](environment-recovery.md)。

导入骨骼可配置 `character.footfall_phase_offset`（循环比例），由该模型的足部接触标记校准。控制器把共享步态相位加上该偏移后映射为动画时间；换模型必须重新校准，不照搬其他骨骼。
