# 环境分层、舒适度与场景恢复

[English](../environment-recovery.md) | **简体中文**

保留地理基础，以可识别的首轮环境和受约束的交互状态继续迭代，接续[表现层](presentation-layers.md)、[语义活动](semantic-activity.md)和[Beta 生命周期](beta-functions.md)。

## 可导出的地面与天空

用已核准、归档、有日期的开放航拍资料提取大范围地表线索，记录原字节、许可、范围／CRS、源图与重采样。平滑颜色后映射到原创小调色板，明确建筑周边、绿地和城市铺装属于合理推断，不是精确地类／通行调查。限制性地图或截图不充当可导出的资产。

presentation v1 可在 `asset_url` 旁提供 `landcover_url`，加载第二个本地 GLB，沿用相对路径约束并由 init-viewer 复制。完整地形覆盖网格标记 `asset_kind: "landscape-surface"`、`surface_layer: "foundation"` 和较小的 `heightfield_offset_m`。**只有覆盖整个地形底面的层才使用 foundation 标记。** 检查与原高程和完整范围一致后，保留原地形供地理核验与物理使用，只关闭其重复绘制；道路、精细铺装使用不同深度偏移在上层显示，避免共面闪烁，不改地理坐标和历史记录。

GLB 烘焙顶点调色与高粗糙度，浏览器可叠原创世界坐标程序颗粒，并用导数随距离淡出细节。链式保留已有材质 hook，兼容 PBR／Toon／空间雾；导出文件无需照片或自定义 shader 才能使用。保留独立可编辑源，明确增加的顶点、面数和下载量。

蓝色渐变天幕和合并的柔边方块云提供不需图片／云阴影的风格化天空。天幕跟随相机，位于世界物体之后，独立于场景雾；减少动态效果时停止云漂移。这是可复用的视觉选项，其他地图可以选择不同天空。

## 四档舒适度

第一视角运动晃动提供 **No／Low／Mid／High**，默认 Low，与人口密度独立。当前垂直／侧向幅度上限为 0／0、3／1、6／2、10.5／3.5 毫米，无滚转。只缩放镜头偏移，不改真实位移步态相位、脚步或骨骼动画；系统减少动态效果在所有档位置零。测试 No 档仍可行走和产生正确落脚。

## 碰撞后受约束绕行

activity v2 可带本地 ENU GeoJSON Polygon／MultiPolygon `pedestrian_regions`。离线内缩实际人行铺装以留足身体空间，并扣除建筑／车行路；保留孔洞、分离区域。缺少范围时只安全让行，不无约束逃逸。

步行受阻先短暂等待，再尝试左右两侧的侧移→平行绕过→原路径连接点。采样每段均位于允许区域，避开当前有高度碰撞体，再检查静态建筑。规划和移动采用一致碰撞余量，使已停在接触位置的角色仍能开始绕行；缓存路径点高度。按正常速度／碰撞逐段行走，最后回归时才更新原路径进度，不瞬移。重试有间隔、角色错开、每帧限制规划请求。窄通道可排队，不借其他生境脱困。

验证静止障碍、无穿透／跳位的成功回归、窄路拒绝、孔洞和静态阻挡。记录真实规划检查次数；平常仍使用缓存路线长度／高度。局部绕行不是完整室内 AI 或通用避障系统。

## Beta 终止状态

接触实验可发出与 HUD 解耦、考虑高度、只触发一次的终止回调。冻结世界与输入，在 **UI 下方**盖 30% 黑色遮罩，再显示居中可访问模态窗口。Escape 不得悄悄恢复已终止的一轮，清除键盘／触控按住状态。避免继承右侧设置面板布局及模糊 backdrop。

如果重启语义是“像刚打开”，**重新载入页面**可完整恢复出生／朝向、相机、密度、声音、舒适度、开发者／Beta 状态及临时导航。未来加入持久偏好必须定义其重置行为。测试重载后的相同出生位置与默认项；终止回调在停止／重开前只发一次。普通 Beta 退出仍可恢复进入前状态。见 [Zombie School 模板](../beta/zombie-school.zh-CN.md)。

地点特定图源、分类、地面源资产、截图和开发日志只在下游；可复用协议、生命周期与实际验证写入上游方法论日志。
