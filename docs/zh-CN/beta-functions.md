# 一级 Beta 功能入口

[English](../beta-functions.md) | **简体中文**

**Beta functions** 与 Settings、About 并列为设置窗口一级页签，不放入 About 内的开发者入口。功能默认关闭，主动勾选才启用，仅切换页签不会改变场景。

`src/beta.js` 用 ID、标题、说明及可逆 `start/stop` 注册实验，同一时刻只启用一个。实验保存所覆盖的地图状态，关闭时恢复并销毁临时实例／资源；切换实验先停止旧实验。启用失败时报告错误并恢复探索。保留三视角、导航、搜索、标签、手机操作；对话框期间暂停模拟，状态条说明当前模式。

实验规则和验证放在独立模板模块，不修改真实地理资产，不永久改变密度偏好，也不把所有未来功能塞进开发者菜单。首个例子是 [ZOMBIE SCHOOL!!!](../beta/zombie-school.zh-CN.md)，包含共享的原创卡通怪物生成器与无战斗追逐沙盒。下游独立选择采用或替换；具体地图／开发日志留在下游，通用生命周期和验证经验进入上游方法论日志。
