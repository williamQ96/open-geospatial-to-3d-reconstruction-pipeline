# 首个闭环路线

本次交付为仓库与规划文档，以下均待实现。

## P0：输入与空间约定

- [ ] 以 Open Campus: UO 的 Memorial Quad 小区域为首个集成案例。
- [ ] 确认一组实际可用、使用条件可接受的点云、地形及可选影像输入。
- [ ] 定义来源记录、区域配置、坐标框架与输出清单的 schema。
- [ ] 建立最小命令行入口、环境说明和版本固定方式。

## P1：地理数据到 Blender

- [ ] 裁剪和转换坐标，验证水平与垂直单位。
- [ ] 从 DTM 或地面点生成地形。
- [ ] 提取建筑候选点与轮廓，生成带质量标记的高度和白模。
- [ ] 生成独立 Blender 资产，并保留稳定 ID 和来源追踪。

## P2：Blender 到交换资产

- [ ] 导出 GLB 与地理元数据、资产清单。
- [ ] 验证单位、轴、原点、法线、几何有效性与引用文件。
- [ ] 将产物交给校园仓库的浏览器预览，完成首次端到端验收。

验收：固定配置和已记录输入能重新生成可加载资产；报告来源状态、地理误差和估算项；替换校园区域配置不需要修改通用算法。

## 后续

- [ ] 使用合成小样本验证坐标与导出，再增加真实数据回归样本。
- [ ] 验证另一地区，检查是否仍有 UO 专用假设。
- [ ] 增加影像辅助分割、摄影测量输入、LOD、瓦片和压缩。
- [ ] 按实际需求扩展 USD 或引擎适配器。
